BreezeCast

NWP Visualization and ML Forecasting

BreezeCast has been created as a personal project to visualize multiple NWP providers along themselves and to experiment with machine learning techniques in forecasting.

NWP for GFS, GEFS, HRRR, ECMWF-IFS-ENS, and ECMWF-AIFS has been sourced by dynamical.org. ECMWF-IFS-HRES has been sourced from Earthmover.

Contact (My LinkedIn) if you have any questions or would like a certain city to be added to the list.
